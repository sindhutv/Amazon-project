# Amazon Project (JavaScript)

An Amazon-inspired e-commerce web application built with **HTML, CSS, and JavaScript**. This project demonstrates core front-end development concepts including dynamic rendering, shopping cart management, checkout functionality, and responsive design.

> **Note:** This project was built as a learning project.

## Features

- Product listing page
- Add and remove items from cart
- Dynamic cart updates
- Checkout page
- Order summary
- Order tracking page
- Responsive design
- Modular JavaScript structure

## Technologies Used

- HTML5
- CSS3
- JavaScript (ES6)
- JSON

## Getting Started

1. Clone the repository.

```bash
git clone https://github.com/yourusername/javascript-amazon-project.git
```

2. Open the project in Visual Studio Code.

3. Install the **Live Server** extension.

4. Right-click `amazon.html` and select **Open with Live Server**.
